# Projeto-2---Cadastro-de-Cliente
O "cadastro de cliente com bD" se refere à criação de um banco de dados de clientes, que é um sistema de armazenamento e organização de informações sobre as pessoas que interagem com sua empresa, usado para entender seu perfil, preferências e hábitos de compra, o que facilita a personalização de serviços de marketing e venda.
